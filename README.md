# ❄️ WarmPaws Next — Winter Pet Care Platform (Next.js Version)

WarmPaws Next is the upgraded Next.js version of the original WarmPaws React project — redesigned for **better performance**, **SEO**, **scalability**, and **modern server-side capabilities**.

This project provides a cozy winter care experience for pet owners to explore **winter pet services**, **seasonal kits**, **expert tips**, and more — with a smooth UI built using **Next.js App Router**, **TailwindCSS**, and **Firebase Authentication**.

## ✨ Features

### 🐾 Core Features
- **Next.js 15 with App Router**
- **Server & Client Components**
- **Firebase Authentication**
  - Google Login
  - Email/Password Sign-in
- **Middleware Protected Routes**
- **Profile Update**
  - Name & Image update
- **Dynamic Services**
  - Loaded from JSON (local API route)
- **Booking Form**
  - Success toast notifications
- **404 Page**
- **Static Pages:** About Us, Contact Us,Pet Safety Guidlines

### ❄️ Winter-Themed Features
- Winter pet care tips
- Winter clothing & accessories section
- Expert vets showcase
- Pet winter safety article/cards
- Cozy hero with gradients & animations

### 💫 UI & Animation
- TailwindCSS 4
- DaisyUI
- Swiper.js (Hero carousel)
- Animate.css (Logo pulse)
- Smooth hover & fade animations

## Installation

```bash
# Clone the repository
git clone https://github.com/AsifAhmedTanjid/WarmPawsNextJS.git

# Go into the project directory
cd WarmPawsNextJS

# Install dependencies
npm install

# Add .env file (use .env.example as template)

# Run the development server
npm run dev
```
